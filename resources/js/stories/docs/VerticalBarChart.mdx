# VerticalBarChart
A vertical distribution chart. Bar heights scale against the largest item value unless `maxValue` is provided.
<Canvas of={VerticalBarChartStories._DocsIntro} sourceState={'shown'} />

Use vertical bars for ordered scales where the labels are short, such as ratings or scores. Each item supports `label`, `percent`, `count`, and an optional `value` used only for height.

## Response counts
<Canvas of={VerticalBarChartStories._Counts} sourceState={'shown'} />

## Fixed scale
By default, the largest item fills the available height. Set `maxValue` when multiple charts need a shared scale or when the scale has a known ceiling.
<Canvas of={VerticalBarChartStories._FixedScale} sourceState={'shown'} />

## Summary
Use the `summary` slot for an average, range, or other aggregate. Include that information in `accessibleLabel` too.
