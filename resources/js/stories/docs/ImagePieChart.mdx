# ImagePieChart
A two-segment pie chart that uses each item's image as its fill. Each item supports a label, badge, percentage, and response count.
<Canvas of={ImagePieChartStories._DocsIntro} sourceState={'shown'} />

Use this for binary image-choice results. Each item should provide `image` and `badge` alongside the shared `label`, `percent`, and `count` values.

## Response counts
Set `metric` to `count` without changing the segment proportions.
